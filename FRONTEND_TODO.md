// API: GET {API}/clusters/{id}/wind -> WindTrace (Cache-Control 1800 s live, 300 s ERA5 fallback)

  API_URL ? getJson<WindTrace>(`${API_URL}/clusters/${id}/wind`)

## 2. RTI draft button (Cluster detail page)

- Where: `ClusterPage`, next to or below the inspection brief (Brief tab), button "Draft an RTI request".
- Call `POST /rti/{id}`; show a preview of `markdown` (same document styling as the brief, no typing reveal
  needed), with **Copy** (copy `plain_text` to the clipboard) and **Download** (`.txt` from `plain_text`, and/or
  `.md` from `markdown`; file name `rti-draft-{id}.txt`).
- Show the footer text prominently: "Draft generated by PanoptiCoal. Not legal advice." It is already the last line
  of the draft.
- Clusters spanning two states (Singrauli: Madhya Pradesh + Uttar Pradesh) return one application per board in one
  document, separated by a rule; the preview should simply render it.
- Static mode (no `VITE_API_URL`): show the same "available in the deployed version" info as the brief.
- Optional: list `flagged_periods` on the page (the RTI asks for records for exactly these dates).

## 3. Wind cone + arrow (Risk Map and Near Me)

- Data: `fetchWind(id)` for the selected/hovered cluster (Risk Map) or the nearest clusters (Near Me).
- Draw `cone_polygon` as a translucent Leaflet polygon (convert GeoJSON `[lon, lat]` to Leaflet `[lat, lon]`,
  or use `L.geoJSON`), plus an arrow from the centroid along `bearing_deg` (rotate an SVG/divIcon by
  `bearing_deg`; 0 = north, clockwise). Mark `towns_in_path` as small labelled dots.
- Show `sentence` under or beside the map, with `attribution` in small type, and a badge for `source`
  ("Live wind" / "ERA5 reanalysis, not current").
- Wording rule: direction only. Do not add concentrations, exposure or health claims to the overlay.
